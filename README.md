# Лабораторная работа №4 (Вариант 18)

Многопроцессное приложение на языке Си под Windows (Win32 API): обмен данными между процессами через отображаемые в память файлы (file mapping) и синхронизация событиями (events)

## Описание
* **Родительский процесс (`parent.exe`)**:
  * Запрашивает имена двух выходных файлов для дочерних процессов;
  * Для каждого потомка создаёт канал: именованное отображение `CreateFileMapping` (на файле подкачки) и два автосбрасываемых события `ready` / `free`;
  * Открывает выходные файлы и порождает `child1.exe` и `child2.exe` (`CreateProcess`), подставляя файл потомку как `stdout`; в командной строке потомок получает только PID родителя и номер канала;
  * Принимает строки от пользователя: нечётные строки кладёт в разделяемую память `child1`, чётные - `child2`;
  * Ждёт освобождения блока вместе с дескриптором потомка (`WaitForMultipleObjects`), поэтому замечает аварийное завершение потомка;
  * В конце передаёт признак `done`, ждёт потомков, выводит их коды возврата и закрывает все дескрипторы
* **Дочерние процессы (`child1.exe`, `child2.exe`)**:
  * Открывают объекты канала по имени (`OpenFileMapping`, `MapViewOfFile`, `OpenEvent`);
  * Не работают с файлами напрямую: удаляют из строки все гласные (латиница и кириллица в UTF-8) и пишут результат в `stdout`, журнал - в `stderr`;
  * Ждут данные вместе с дескриптором родителя: если родитель завершился, потомки тоже корректно завершаются
* Все сообщения журнала содержат PID и TID процесса

## Структура
* `include/channel.h`, `src/channel.c` - разделяемая память и события (канал родитель -> потомок)
* `src/parent.c` - родительский процесс
* `src/child.c` - дочерний процесс
* `include/vowels.h`, `src/vowels.c` - удаление гласных
* `include/utils.h`, `src/utils.c` - вывод ошибок (`GetLastError` + `FormatMessage`), журнал с PID/TID, чтение строк
* `procmon.CSV` - журнал Process Monitor

## Сборка и запуск

Сборка компилятором GCC (MinGW / MSYS2):
```bash
mingw32-make
```

Запуск:
```bash
./parent.exe
```

Запуск с готовым вводом (имена файлов и строки):
```bash
./parent.exe < input.txt
```

Трассировка: Process Monitor (Sysinternals, от имени администратора), фильтр `Process Name is parent.exe / child1.exe / child2.exe`, запуск из PowerShell:
```powershell
cmd /c "parent.exe < input.txt"
```
Журнал сохранён в `procmon.CSV`

Очистка:
```bash
mingw32-make clean
```

Отчёт: `report/report.docx`
